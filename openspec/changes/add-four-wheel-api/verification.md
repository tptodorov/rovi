# M6 verification map

Rows name implemented software checks and separately identify physical acceptance still pending. Test names were checked against the compiled test lists in task 3.6: 173 core, 25 motor-control and 10 coordinator tests (including task 5.2 Echo preparation). Each row covers the scenarios under that requirement; a software pass does not close its physical checks. Task numbers refer to [tasks.md](tasks.md).

Host: deterministic tests/recording driver. Integration: real sockets or Jazzy on the laptop. Physical: separately authorized product firmware bench evidence; old M4/M5 evidence is a reference only.
