# Confirm dev board vs. bare chip before any HW design

M1's first `wiring.kicad_sch` used generic chip-datasheet symbols (6-9 pins, arbitrarily numbered "Pin 1"/"Pin 2") without asking whether the design targeted the bare ESP32-S3/TB6612FNG chips or the specific dev boards actually purchased. It matched the datasheets correctly but not the physical boards — different pin count, different numbering, nothing printed on the real silkscreen corresponded to a "pin 3" in the diagram. Fixing it meant rebuilding both symbols from scratch as full 44-pin/16-pin representations of the actual boards in `docs/reference/`. Decided: for any future wiring diagram, schematic, or PCB layout, ask up front whether the design is for dev boards or bare chips, and if dev boards, exactly which ones — never assume.
